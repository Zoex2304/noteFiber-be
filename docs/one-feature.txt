### 3. Controller Layer (chatbot_controller.go)
```go
// Interface definition
type IChatbotController interface {
    RegisterRoutes(r fiber.Router)
    CreateSession(ctx *fiber.Ctx) error
    GetAllSessions(ctx *fiber.Ctx) error
    GetChatHistory(ctx *fiber.Ctx) error
    SendChat(ctx *fiber.Ctx) error
    DeleteSession(ctx *fiber.Ctx) error
}

// Route registration
func (c *chatbotController) RegisterRoutes(r fiber.Router) {
    h := r.Group("/chatbot/v1")
    h.Get("sessions", c.GetAllSessions)
    h.Get("chat-history", c.GetChatHistory)
    h.Post("create-session", c.CreateSession)
    h.Post("send-chat", c.SendChat)
    h.Delete("delete-session", c.DeleteSession)
}
```

## Architecture Overview

The chatbot feature follows a clean architecture pattern with the following layers:

1. **Presentation Layer** (Controller)
   - Handles HTTP requests
   - Input validation
   - Response formatting

2. **Service Layer**
   - Business logic implementation
   - Integration with Gemini chatbot
   - Session management
   - Chat history handling

3. **Repository Layer**
   - Data persistence
   - Database operations for:
     - Chat sessions
     - Chat messages
     - Raw chat messages

4. **Entity Layer**
   - Data models
   - Database schema representation

5. **DTO Layer**
   - Request/Response objects
   - Data transfer between layers

6. **Core Package**
   - Gemini chatbot implementation
   - Core chatbot functionality

## API Endpoints

1. GET /api/chatbot/v1/sessions
   - Get all chat sessions

2. GET /api/chatbot/v1/chat-history
   - Get chat history for a specific session

3. POST /api/chatbot/v1/create-session
   - Create a new chat session

4. POST /api/chatbot/v1/send-chat
   - Send a message in a chat session

5. DELETE /api/chatbot/v1/delete-session
   - Delete a chat session

## Database Schema

The chatbot feature uses three main tables:

1. chat_session
   - Stores chat session information
   - Manages session lifecycle

2. chat_message
   - Stores processed chat messages
   - Links messages to sessions

3. chat_message_raw
   - Stores raw chat messages
   - Used for message processing
