## 4. API Documentation

### Endpoints

1. `POST /api/chatbot/v1/create-session`
   - Creates new chat session
   - Initializes with system prompts
   - Returns session ID

2. `GET /api/chatbot/v1/sessions`
   - Lists all chat sessions
   - Includes metadata
   - Supports pagination

3. `GET /api/chatbot/v1/chat-history`
   - Retrieves session messages
   - Chronological ordering
   - Role-based filtering

4. `POST /api/chatbot/v1/send-chat`
   - Processes user messages
   - Generates responses
   - Updates session state

5. `DELETE /api/chatbot/v1/delete-session`
   - Removes chat sessions
   - Handles related messages
   - Supports soft deletion

## 5. Database Schema

### 5.1 Chat Session Table
```sql
CREATE TABLE chat_session (
    id UUID PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    created_at TIMESTAMP NOT NULL,
    updated_at TIMESTAMP,
    deleted_at TIMESTAMP,
    is_deleted BOOLEAN DEFAULT FALSE
);
```

### 5.2 Chat Message Table
```sql
CREATE TABLE chat_message (
    id UUID PRIMARY KEY,
    chat TEXT NOT NULL,
    role VARCHAR(10) NOT NULL,
    chat_session_id UUID NOT NULL,
    created_at TIMESTAMP NOT NULL,
    updated_at TIMESTAMP,
    deleted_at TIMESTAMP,
    is_deleted BOOLEAN DEFAULT FALSE,
    FOREIGN KEY (chat_session_id) REFERENCES chat_session(id)
);
```

### 5.3 Raw Message Table
```sql
CREATE TABLE chat_message_raw (
    id UUID PRIMARY KEY,
    chat TEXT NOT NULL,
    role VARCHAR(10) NOT NULL,
    chat_session_id UUID NOT NULL,
    created_at TIMESTAMP NOT NULL,
    updated_at TIMESTAMP,
    deleted_at TIMESTAMP,
    is_deleted BOOLEAN DEFAULT FALSE,
    FOREIGN KEY (chat_session_id) REFERENCES chat_session(id)
);
```

## 6. Implementation Details

### 6.1 Message Flow
1. User sends message
2. System decides RAG usage
3. If RAG needed:
   - Generate embeddings
   - Search similar content
   - Enhance context
4. Process with Gemini
5. Store raw and processed
6. Return response

### 6.2 Session Lifecycle
1. Creation
   - Generate UUID
   - Initialize prompts
   - Set metadata
2. Active Use
   - Message processing
   - Context management
   - Title updates
3. Deletion
   - Soft delete
   - Related cleanup

### 6.3 RAG Process
1. Embedding Generation
   - Text vectorization
   - Model: gemini-embedding-exp-03-07
   - Task-specific processing
2. Similarity Search
   - Vector comparison
   - Relevance ranking
   - Context selection
3. Response Enhancement
   - Context integration
   - Reference management
   - Language adaptation
